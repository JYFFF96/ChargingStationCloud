# ChargingStationCloud

微信扫码充电小程序前端。

## V0.2

当前版本可在不连接后台和真实充电桩的情况下体验完整流程：

1. 首页扫码 / 模拟扫码
2. 确认设备与充电枪
3. 模拟启动充电
4. 查看充电时长、电量、费用及实时参数
5. 停止充电
6. 查看充电结果
7. 本地保存充电记录

## 当前开发模式

- `config.js -> mockEnabled: true`
- 模拟二维码：`CS-DEMO-0001`
- 二维码真实格式尚待后台确认
- 后台 API 尚未接入
- 充电参数、价格均为模拟数据

## 后续接口

待后台提供接口后接入：设备查询、开始充电、充电状态、停止充电、订单/记录、用户认证。

> 本仓只维护微信小程序前端，不包含后台、云平台、数据库或充电桩通信服务。
